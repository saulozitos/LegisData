# LegisData Frontend

Interface web moderna em **Next.js 16 (App Router & Turbopack)**, **React 19**, **TypeScript** e **Tailwind CSS** para a plataforma LegisData.

## Execução Local

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Build de Produção

```bash
npm run build
```
